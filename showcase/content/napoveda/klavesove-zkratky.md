| Zkratka                   | Co udělá                                    |
| ------------------------- | ------------------------------------------- |
| <kbd>⌘</kbd> <kbd>P</kbd> | paleta příkazů — skok kamkoli a rychlé akce |
| <kbd>⌘</kbd> <kbd>N</kbd> | nová faktura                                |
| <kbd>⌘</kbd> <kbd>S</kbd> | uloží otevřený formulář                     |
| <kbd>⌘</kbd> <kbd>,</kbd> | nastavení                                   |
| <kbd>⌘</kbd> <kbd>Q</kbd> | ukončí appku                                |

Paleta je nejrychlejší cesta všude jinam: začni psát název sekce nebo akce
a potvrď <kbd>Enter</kbd>.

Zbytek appky se ovládá standardně — <kbd>Tab</kbd> mezi poli, <kbd>Enter</kbd>
potvrzuje, <kbd>Esc</kbd> zavírá dialogy.
